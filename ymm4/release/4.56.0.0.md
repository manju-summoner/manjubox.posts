## 追加
- 場面切り替え「キューブ回転」「裏返し」「ランダムライン」「縮小回転」「スワップ」「起き上がる」「見開きめくり」「明転・暗転」を追加。
- 映像エフェクト「ランダムライン」「ランダムラインで登場退場」「見開きめくり」「見開きをめくりながら登場退場」を追加。
- キャラクター設定にエクスポート機能を追加。
- 「グラデーション」エフェクトの位置とサイズを描画対象に対する割合で指定できるようにした
- VOICEVOX「夜語トバリ」「暁記ミタマ」「里石ユカ」に対応
- OpenAI音声合成で選択出来る音声一覧に「marin」「cedar」を追加
- 図形の「線」の「点の形」を「破線」から「丸め処理」に移動。実線・破線を問わず設定できるように変更。「長さ」や「位置」をずらした端の形を変更できるようにした。
- 「パペット変形」「ベクトル場変形」エフェクトのピン配置用の画像を、グループ制御（合成）・画面の複製・エフェクトアイテムでも表示できるようにした
- Irodori-TTSの依存関係が足りずサーバーを起動できない場合に、環境に合わせて依存関係を自動的に導入するようにした
## 修正
- 動画・音声アイテムのファイルを変更したりボイスアイテムのセリフを変更したりすると、設定していた再生開始位置と、手動で変更したアイテムの長さがリセットされてしまう問題を修正
- 透過画像に「ページめくり」「見開きめくり」を適用すると、めくったページが落とす影が画像の形ではなく画像の矩形に沿って表示される問題を修正
- 「Piper Plus」の音声合成エンジンをv1.13.0に更新
- exo出力すると「放射光」の強さ・サイズ固定、「放射ブラー」「円形ブラー」のサイズ固定、「モノラル化」の比率がAviUtlで反映されず既定値に戻る問題を修正
- exo出力すると「ディスプレイスメントマップ」のぼかしがAviUtlで反映されない問題を修正
- exo出力すると、キーフレームを設定したアイテムの2つ目以降のキーフレーム区間で、「アニメーションなし」「移動量指定」「反復移動」「ランダム移動」を設定したパラメータがAviUtlで正しく再現されない問題を修正
- 「波打ち」エフェクトの「波長」に指定した値と実際の波の間隔が一致していない問題を修正
- exo出力すると「波打ち」の波のスクロール速度と波打つ向きがAviUtlで再現されない問題を修正
- 「ルミナンスキー」エフェクトの透過モード「しきい値部分を透過」で、なめらかさを0%にすると何も透過されない問題を修正
- 「パペット変形」エフェクトの変形方式「なめらか（MLS）」で、ピンを打った場所が局所的にボケて表示される問題を修正
- タイムラインのレイヤーの右クリックメニューの「すべて選択(A)」がアクセスキー（A）で実行できない問題を修正
- タイムラインの目盛りをドラッグしてシークしている最中にマウスホイールでスクロールすると、再生位置がカーソルの位置からずれる問題を修正
- 再生開始位置や再生速度によっては、動画アイテム・「テクスチャ」「背景画像」エフェクト・画像ブラシのプレビュー・出力で同じフレームが繰り返し表示されて映像がカクつく問題を修正
- 時刻（hh:mm:ss.ff）表示の入力欄で、値を編集していなくても入力欄から他所へフォーカスを移すと値が変わってしまう問題を修正
- 時刻（hh:mm:ss.ff）表示の入力欄で、上下キーやホイールでフレーム単位の増減を繰り返すと値がフレームの境界から少しずつずれていく問題を修正
- 数値の入力欄で、値を編集していなくても入力欄から他所へフォーカスを移すと値が表示上の桁数まで丸められてしまう問題を修正
- アイテムの先頭をドラッグして長さを変える操作を繰り返すと、再生開始位置がフレームの境界から少しずつずれていく問題を修正
- アイテムの末尾をドラッグして隣接するアイテムを押し縮め・引き伸ばししたとき、隣接するアイテムの再生開始位置が再生速度を無視した値になり、操作を繰り返すとフレームの境界からずれていく問題を修正
- ウイルス対策ソフトの影響でアップデート時のファイルの比較結果が保存されず、比較に毎回時間がかかることがある問題を修正
- ウイルス対策ソフトがファイルを検査している間にアップデートすると、実際には更新できる状態でも「他のアプリケーションで使用されているため、アップデートを中断しました」と表示されて更新できないことがある問題を修正
- 分割した動画を多数配置したプロジェクトで、プレビュー再生が分割位置の手前で一瞬止まる問題を修正
- 編集ファイルを開いたりシーンを切り替えたりすると、環境によっては画面に黒い矩形が最前面に残り続けることがある問題を修正
- HDR動画をFFmpegで読み込むと、映像が白飛びする問題を修正
- フルレンジで記録された動画をFFmpegで読み込むと、暗い部分が黒く潰れ、明るい部分が白飛びする問題を修正
- 動画をFFmpegで読み込むと、動画に記録された色の規格（BT.709／BT.601／BT.2020）が無視されて色味がずれる問題を修正
- CSSで色を指定したSVGファイルを読み込むと、指定した色が反映されず黒く表示される問題を修正
- SVGファイルで使い回されている図形（use要素など）が、書き出したツールによっては描画されない問題を修正
- SVGファイルによっては、読み込んだ絵がずれて端が欠けたり、何も表示されなかったりする問題を修正
- 一部のSVGファイルの読み込みに失敗したときにメモリリークする問題を修正
- ハードウェアデコードが使われない環境でmkvの動画を読み込むと、映像のフレームレートが半分になる問題を修正
- 文字間隔を設定したテキストに文字毎に適用するエフェクトを使うと、行末の文字だけ位置がずれて文字が等間隔に並ばない問題を修正
- 「選択中のAquesTalk系ボイスを棒読み化」を実行しても、発音欄の表示だけが変わって音声が更新されない問題を修正
- VoiSona Talkで、一度音声を生成した後に話速やスタイルなどを変更しても音声に反映されない問題を修正
- 図形の「線」で開始点・終了点の形を設定しても、線の長さや太さによっては終了点側だけ設定と違う形で表示されることがある問題を修正
- 図形の「線」で実線を選んで線を閉じたとき、線の始点と終点の継ぎ目が繋がらずに欠けて見えることがある問題を修正
- 再生速度を「瞬間移動」のアニメーションで切り替えると、切り替えた後の区間で表示される映像が最大1フレーム分ずれる問題を修正
- シーンアイテムの再生速度をアニメーションする・逆再生する・再生速度変更方式を「SOLA / 音程維持」にすると、シーン内の音声が少し前の音と重なって繰り返し聞こえる問題を修正
- シーンアイテムに音声エフェクトの「音程」「再生速度（音程維持）」を適用する、または音声エフェクトの「再生速度」で速度をアニメーションする・マイナスにする・再生速度変更方式を「SOLA / 音程維持」にすると、シーン内の音声が少し前の音と重なって繰り返し聞こえる問題を修正
- 音声エフェクトの「再生速度（音程維持）」「音程」を100%のまま使うと、音質が変化して処理も重くなる問題を修正
- 背景に何も置いていない状態でWebPに出力すると、残像が表示される問題を修正
- 一部のアニメーションWebPを読み込むと、アニメーションが再生されず1枚目の絵のまま止まる問題を修正
- 「出力を分岐」「分岐と合成」と「前景塗りつぶし」「背景塗りつぶし」「余白」エフェクトを組み合わせると、プレビュー再生中に「グラフに構成エラーが見つかりました。」というエラーが発生する問題を修正
- 「出力を分岐」「分岐を切替」「分岐と合成」エフェクトを使うと、それより後ろの「縁取り」が本来より太く表示される問題を修正
- 「出力を分岐」「分岐を切替」「分岐と合成」エフェクトを使うと、プレビュー上でアイテムの左右に縦線が表示されることがある問題を修正
- 新しいシーンを作った後に他のシーンやメインへ切り替えると、一番右のシーンタブが空白になって選択できなくなることがある問題を修正
- シーンタブが多くて横スクロールが必要な状態で、メニューからシーンを選んだり新しいシーンを作ったりすると、選択したシーンのタブが画面外のままになる問題を修正
- 「絵画調」エフェクトを適用すると、まれに映像にノイズ状の点が混ざることがある問題を修正
- テキストの「文字ごとに分割」と「表示間隔」または「非表示間隔」を設定すると、文字が1文字ずつ表示・非表示になっている間、ランダムアニメーション時に文字がガクガクと震える問題を修正
- 「画像貼り付け」「背景画像」エフェクトの拡大率を0%に近づけると、プレビューや出力が極端に遅くなる問題を修正
- タイムラインの背景色を設定した状態でグループ制御（合成）を使うと、合成結果に画面全体の背景色が含まれる問題を修正
- テキストや字幕で文字サイズやフォントを変える制御タグ（&lt;s&gt;）を使うと、最終行だけ描画位置が下にずれる問題を修正
- テキストや字幕で文字サイズやフォントを変える制御タグ（&lt;s&gt;）を使うと、大きい文字を含む行の下にだけ余分な余白が入って次の行が下にずれる問題を修正
- テキストや字幕で文字サイズやフォントを変える制御タグ（&lt;s&gt;）を使うと、「行間」を100%以外にしたときにテキスト全体の表示位置がずれる問題を修正
- テキストや字幕で「文字ごとに分割」と「表示間隔」または「非表示間隔」を設定し、「表示方向」または「非表示方向」を「末尾から」にすると、文字が1文字ずつ表示・非表示になるタイミングが1間隔ぶん遅れる問題を修正
- テキストや字幕でルビ（&lt;rb&gt;）と「表示間隔」または「非表示間隔」を設定し、「表示方向」または「非表示方向」を「末尾から」にすると、「文字ごとに分割」を設定していない場合にルビだけが親文字より1間隔ぶん遅れて表示・非表示になる問題を修正
- テキストや字幕で改行より後ろにルビ（&lt;rb&gt;）を置くと、ルビの大きさと縦位置が親文字ではなく前の行の文字サイズで決まってしまう問題を修正
- テキストや字幕で文字を回転させる制御タグ（&lt;rot&gt;）を使うと、絵文字や異体字セレクタ（☀️など）、合字を含む範囲で回転の中心が本来より手前にずれる問題を修正
- テキストや字幕で「表示間隔」「非表示間隔」を設定すると、絵文字や一部の漢字、異体字セレクタ付きの絵文字（☀️や❤️など）、複数の絵文字を組み合わせた絵文字、結合文字を含むテキストで、文字が現れる・消える順序や間隔が崩れる問題を修正
- テキストや字幕で「表示間隔」「非表示間隔」と制御タグを併用すると、文字が1文字ずつ表示・非表示になっている間だけ、まだ表示されていない文字や既に消えた文字の数だけ打ち消し線・下線・座標（&lt;p&gt;）・回転（&lt;rot&gt;）が手前の文字にずれて適用される問題を修正
- テキストや字幕で「表示方向」「非表示方向」を「ランダム」にすると、テキストを編集した後も編集前の文字数のままの順序が使われ、複数の文字が同時に現れる・消えることがある問題を修正
- テキストや字幕で表示速度を変える制御タグ（&lt;r&gt;）や待機（&lt;w&gt;）・クリア（&lt;c&gt;）を使うと、絵文字や一部の漢字（サロゲートペア）、異体字セレクタ付きの絵文字（☀️や❤️など）を含むテキストで、その文字が2文字分の時間を使って後ろの文字の表示が遅れる問題を修正
- テキストや字幕で「表示間隔」「非表示間隔」や表示速度を変える制御タグ（&lt;r&gt;）を使うと、「文字ごとに分割」の有無で文字が現れる・消えるタイミングが1フレームずれる問題を修正
- テキストや字幕で「表示方向」「非表示方向」を「ランダム」にすると、「文字ごとに分割」の有無で現れる・消える文字の順序が逆向きになる問題を修正
- シーンのタブ列の「新しいシーンを作成」ボタンを押すと、押したボタンとは別の場所に新しいシーンのタブが追加されることがある問題を修正
- COEIROINK2で一部音源を追加している場合、キャラクターを読み込めなくなる問題を修正
- 圧縮ファイルの中のファイルをコピーしてタイムラインに貼り付けると、エラーが発生して貼り付けられないことがある問題を修正
- Adobe RGBなど、sRGB以外のカラープロファイルが埋め込まれた画像を読み込むと、色味が変わって見える問題を修正
- シーンアイテムの再生速度によっては、シーンの最後のフレームが表示されず、ループ再生時に点滅する問題を修正
- シーンアイテムを逆再生すると、先頭のフレームが表示されない問題を修正
- 動画アイテムを逆再生とループを併用して再生すると、2周目以降の映像が表示されない問題を修正
- エフェクト「テクスチャ」「背景画像」で動画の再生速度をマイナスにすると、映像が正しく表示されない問題を修正
- VOICEVOXの音声合成に失敗したとき、エラーの内容が表示されないことがある問題を修正
- 図形アイテム・「図形切り抜き」エフェクト・エフェクトアイテムの領域で「矢印」「くさび形」の「へこみ」を設定すると、へこみの部分に細い線が残る問題を修正
- 録音した音声を再生すると、YMM4自体の音量（Windowsの音量ミキサーで設定する音量）が変わってしまう問題を修正
- エクスプローラーツールを閉じた後にエラーが表示されてYMM4が終了することがある問題を修正
- 「パペット変形」「ベクトル場変形」エフェクトを選択したまま再生やシークを行うと動作が重くなり、グループ制御に適用している場合などにYMM4が強制終了することがある問題を修正
- 「パペット変形」「ベクトル場変形」をグループ制御など表示範囲が非常に大きいアイテムに適用すると、ピン配置用の画像が表示されないことがある問題を修正
- 画面の複製やエフェクトアイテムに「パペット変形」「ベクトル場変形」エフェクトを追加すると、YMM4が強制終了することがある問題を修正
- VoiSona Talkのボイスの「言語」を設定しても音声合成に反映されない問題を修正
- Irodori-TTSでGPUを使うように環境を用意していても、YMM4からサーバーを起動するとCPUで音声合成が行われる問題を修正
- ファイルの保存先に「&lt;ProjectDir&gt;」等が指定されている状態で、プロジェクトを保存する前にファイルのドラッグ＆ドロップや貼り付けを行うとエラーになる問題を修正
- ファイルの保存先に「&lt;ProjectDirName&gt;」のみが指定されている場合、プロジェクトを保存する前に取り込んだファイルが「_ProjectDirName_」という名前のフォルダに保存されてしまう問題を修正
- ファイルの保存先に「&lt;ProjectDir&gt;」等が指定されている場合、プロジェクトを保存するまで設定画面の保存先のサンプルが空欄になる問題を修正
